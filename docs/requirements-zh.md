# 企业内部即时通讯平台需求（中文原文）

> 来源：客户提供的中文需求。为避免改变客户原意，正文按原文保存，仅增加 Markdown 排版。

## 概述

这是一款面向小型团队的企业内部及时通讯。

作为一个项目成员我希望在群里可以@某人，方便对方能及时看到我的消息，具备一对一私聊、群聊、消息列表，文件和图片传输、消息已读未读、视频和语音通话，消息的延迟不超过1秒支持1000人以上在线，消息内容加密传输，原型可以比其他社交软件。

## 聊天前端具体细节

### 1. 注册与登录

注册，手机号码注册，通过企业内部邀请码进入该企业名下内部聊天，A企业邀请码是永久有效可以多次使用，b企业邀请码也是可以永久有效并且多次使用。

1. 手机注册是需要11位手机号码注册即可，登陆时需要图形验证码防刷。
2. 注册登陆动态权限：支持手机和电脑同时可以在线，新设备登录后旧设备踢掉，登录有效期可以记住我的密码60天内。
3. 登录可以使用密码进行登录，密码设置全使用阿拉伯数字或者字母+阿拉伯数字（如：12345678或abc123456）密码至少8位数，不需要设置找回密码服务。

### 2. 个人资料

修改个人资料包括更改头像，名称，姓名年龄，地区，个性签名。个人资料可设置是否公开或者好友可见。

1. 头像上传格式（jpg/png/gif）肯定越多越好，最大文件大小限制100mb。
2. 名称设置不允许重复和使用特殊符号，可以使用表情。

### 3. 群聊与好友

群聊板块，好友之间创建并邀请进群也可以搜索群聊ID进群，需要群管理员审核通过。群主有权分配管理权限。管理权限有：消息撤回、邀请人进群、踢人出群、群内禁言模式开启与关闭、设置管理员。

1. 群人数上线1000人以上。
2. 群主与管理员有权修改群昵称、群头像、群公告、群简介、群内置顶某信息、群内禁止互相添加好友，其余非群主和管理员无权限进行任何操作。
3. 加群方式：通过管理员或者群主进行邀请制，也可以通过群二维码或者群ID进行搜索加入，所有方式需要通过群管理员或群主审核验证后同意加入。
4. 群内权限细节：消息撤回后，仅管理员和群主可以见撤回提示，其余群员无法看见撤回消息的提示。群内消息禁言需要支持全员禁言除管理员和群主，也需要支持选择特定成员禁言可设置10分钟、1小时、永久，群主可以设置管理员无上限。被踢出的成员或主动退出群聊的成员，其他人不可见退出提示，群管理和群主可见。新成员进入不可以看到入群前的历史信息。
5. 好友方式验证可以细化为三种模式：允许任何人添加我为好友（无需验证）；需要验证（发送好友申请，对方同意后通过）；禁止任何人添加我（关闭所有加好友渠道）。
6. 好友可以互相看到在线状态，一个账号最多能添加1000好友，允许好友之间设置备注以及标签。

### 4. 聊天页面

聊天页面功能涵盖文字、表情、贴纸、GIF、语音条、视频和语音通话。

1. 文字消息单条消息最大1000字上限。
2. 支持内置表情、贴纸包与 GIF 搜索发送。
3. 语音消息最长录制不超过60秒。
4. 可以支持先录制后发送，支持上传视频文件发送，也可以实现实时视频通话，建议可发送视频文件我们根据情况而定。
5. 图片和文件发送支持的格式和单个大小。
6. 1V1私聊消息，显示发送成功标志并“已读”或未读，所有信息都支持复制消息、转发消息，一键可以选择指定的转发给好友和群聊。群聊和私聊中具备“引用”某条信息进行回复。群聊和私聊中支持“@某人”或“所有人”。所有聊天记录需要保存3个月以上。

## 平台、通知与容灾

- 平台兼容 iOS/Android/Web/Windows/Mac。
- 手机 App 在后台时，需要保证新消息的及时提醒，需要对接各厂商的推送服务。
- 需要定制备份机制，服务器故障时，数据恢复。

## 后台软件功能

1. 加白号，对特殊地区无法使用手机号码下载，给予加白设置或者帮助注册账号。
2. 有随时可以对任何ID账号施行封禁登录功能。
3. 可以随时调看任何一个企业下的ID号所有聊天记录。
4. 对所有ID账号的把控，若有人遗忘密码，也可以随时为其更改密码或者查询密码。
5. 支持各平台兼容登录。
6. 隐私性以及安全性，防火墙防盗防黑客防追踪很重要。
7. 需要有终端和子账户进行管理，终端可下发每个企业后台管理账户并且具备以上功能。
8. 可查看每个ID注册IP地址和地区信息。
