# XinChat macOS desktop release

Build on a **Mac** (Apple Silicon or Intel). Cannot cross-build `.dmg` on the Linux VPS.

## Prerequisites

- macOS with Xcode command line tools
- Node.js 22+
- Apple Developer account (for distribution outside direct download)

## Build

```bash
cd apps/xin-desktop
cp .env.example .env   # optional XINCHAT_WEB_URL override
npm ci
npm run check
npm run dist:mac
# With update metadata for auto-update feed:
npx electron-builder --mac dmg --publish always
```

Artifact: `dist/xinchat-desktop-0.1.0-arm64.dmg` (name varies by arch).

## Publish download page

On the VPS (or any machine with the `.dmg`):

```bash
# copy dmg into apps/xin-desktop/dist/ then:
./scripts/sync-xin-installers.sh
make publish-xin
# or full pipeline: make publish-xin-full
```

Update `apps/xin-web/public/downloads/manifest.json` if the filename differs from `xinchat-desktop-0.1.0-arm64.dmg`.

## Auto-update feed

```bash
make sync-xin-desktop-updates DEST=/var/www/xin-desktop-updates
```

Include `latest-mac.yml` if generated by `--publish always`.

## Notarization (App Store / wide distribution)

Set signing env before build (never commit):

```bash
export CSC_LINK=/path/to/DeveloperID.p12
export CSC_KEY_PASSWORD=...
export APPLE_ID=...
export APPLE_APP_SPECIFIC_PASSWORD=...
export APPLE_TEAM_ID=...
npm run dist:mac:signed
```

See `apps/xin-desktop/README.md` and `scripts/afterSign.js`.
